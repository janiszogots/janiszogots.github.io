ConsentAlly test pages

Each page loads the ConsentAlly shim first, then tries to load trackers. Open DevTools (Network and Application tabs) and check that nothing below loads and no tracker cookie is set before you choose in the banner.

  • Static trackers: Google Analytics 4, Google Tag Manager, Meta Pixel, TikTok, Hotjar, Microsoft Clarity, LinkedIn, Pinterest, Klaviyo, in the page's HTML
  • Late-injected trackers: scripts, pixels, fetch, XHR and beacons added after load, on a timer, on scroll, on click and on "add to cart"
  • Embeds and media: YouTube, Vimeo and Google Maps, video, link preloads, an inline-HTML frame and a web worker
  • Manual tags: the same trackers written as type="text/plain" manual tags, so nothing is downloaded before consent
  • Unknown third parties: scripts from hosts no tracker list knows, which must be held as marketing
