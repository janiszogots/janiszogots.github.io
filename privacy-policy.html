Privacy Policy

Last updated: July 7, 2026

This is a test website used for QA purposes. This privacy policy describes what information this site does and does not collect from visitors.

Information we collect

This website does not collect, store, or process any personal information. No accounts can be created and no forms submit data to a server.

Cookies

This site does not set cookies. Embedded third-party tools may use browser storage for functional purposes, such as remembering accessibility preferences.

Third-party services

This site is hosted on GitHub Pages. GitHub may collect technical data such as IP addresses in server logs. See the GitHub Privacy Statement for details. This site also embeds the Inclusify accessibility widget, which counts unique visits without identifying individual visitors.

Your rights

Since no personal data is collected, there is nothing to request, correct, or delete. Questions can be directed to the site owner via GitHub.

Changes to this policy

Any changes to this policy will be published on this page.
